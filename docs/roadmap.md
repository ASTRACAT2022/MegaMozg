# Roadmap

## Phase 1

- Monorepo scaffold
- Go control plane with in-memory API
- Next.js panel shell
- Rust node scaffold
- OpenAPI contract and AI orchestration design

## Phase 2

- PostgreSQL persistence
- Redis-backed queues and ephemeral job state
- operator accounts, RBAC, audit log
- live node inventory updates
- rollout engine with pause thresholds

## Phase 3

- gRPC streaming between Meza-Core and Meza-Node
- log fan-in and real-time task output
- typed privileged job execution
- package and service operations
- signed agent self-update

## Phase 4

- Gemini function calling integration
- approval workflow for sensitive jobs
- AI copilot conversation history
- risk classification and suggested rollout modes

## Phase 5

- Prometheus and Grafana integration
- Telegram notifications
- canary channels for agent updates
- multi-region control plane readiness
